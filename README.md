# Mobile Sales Dashboard | Power BI

## Overview
An interactive Power BI dashboard built to analyze mobile sales performance, payment methods, and regional sales trends using visual analytics.

---

## Features
- KPI Cards for Sales, Quantity, Transactions, and Average Sales
- Brand-wise and Model-wise Sales Analysis
- City-wise Sales Map
- Payment Method Analysis
- Daily Sales Trends
- Interactive Filters and Slicers

---

- Power BI
- DAX
- Power Query
- Excel
